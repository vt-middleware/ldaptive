## Ldaptive 

[![Maven Central](https://img.shields.io/maven-central/v/org.ldaptive/ldaptive?style=for-the-badge&logo=apachemaven)](https://central.sonatype.com/artifact/org.ldaptive/ldaptive)
[![GitHub Releases](https://img.shields.io/github/release/vt-middleware/ldaptive.svg?style=for-the-badge&logo=github)](https://github.com/vt-middleware/ldaptive/releases)

LDAP library for Java.

Ldaptive in a nutshell:

* Simple API for interacting with LDAP servers
* Support for connection pooling
* Authentication API
* Support for SSL/startTLS

This project is dual licensed under both the LGPL and Apache 2.

### Building
```sh
git clone git@github.com:vt-middleware/ldaptive.git
cd ldaptive
./mvn_cmd package
```
